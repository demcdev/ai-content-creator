# animaciones/papel-recortado/
- `papel.py`: piezas de papel (borde cortado o rasgado, fibras, bisel, sombra) y planos con paralaje.
- `pintura.py`: texturas y volumen (pinceladas, empaste, textura de papel, ruido).

Faltan `estilo.py` y `escenas_base.py` para que la tubería lo use por completo. Ejemplo de uso: `Video 02/Montaje/video02_papel.py`.
